# Onderzoek — Zoek je school

Bronnenonderzoek per thema. **Deze bestanden laden nooit vanzelf**: ze staan buiten
`CLAUDE.md` en buiten `.claude/rules/`, en kosten dus geen context tot iemand ze opent.

Open het bestand dat bij je vraag hoort. Alles hier is geverifieerd door de bron effectief op
te halen; wat niet geverifieerd is, staat er met zoveel woorden bij.

| Bestand | Lees dit wanneer |
| --- | --- |
| [databronnen.md](./databronnen.md) | Je zoekt een nieuw gegeven over scholen, of je wil weten waarom iets níét in de app zit |
| [dataopslag.md](./dataopslag.md) | Je overweegt `vestigingen.json` te splitsen of anders te laden |
| [campusgroepering.md](./campusgroepering.md) | Je wil weten waarom scholen op adres gegroepeerd worden, en niet op bestuur |
| [leerlingenkenmerken.md](./leerlingenkenmerken.md) | Je raakt de GOK-cijfers, of je zoekt cijfers per vestigingsplaats in plaats van per school |
| [openbaar-vervoer.md](./openbaar-vervoer.md) | Je wil aan de reistijd met bus of trein werken, of je zoekt een De Lijn-endpoint |
| [fietsroute.md](./fietsroute.md) | Je raakt de fietsroute, de ORS-key of de Netlify-proxy |
| [scholenkompas.md](./scholenkompas.md) | Je zoekt dropouts, doorstroom naar het hoger onderwijs of andere schoolcijfers |
| [aanmelden.md](./aanmelden.md) | Je wil aanmeldsystemen tonen of linken |
| [matrix-studiedomein.md](./matrix-studiedomein.md) | Je werkt aan de matrix, of je zoekt het studiedomein van een richting |
| [kleur-en-kaart.md](./kleur-en-kaart.md) | Je wijzigt het palet, of je raakt de clustering op de kaart |

Wat er nog moet komen staat in [ROADMAP.md](../../ROADMAP.md), wat een bezoeker gemerkt heeft
in [CHANGELOG.md](../../CHANGELOG.md), en wat kapot is als
[GitHub Issue](https://github.com/stefanbckn/Zoek-je-school/issues).
